Скрипт написан на **AutoHotkey v2**. Работает по аналогии со всплывающими подсказками на смартфонах: предлагает варианты слов, продолжение фраз и предсказывает следующее слово или часто вводимую ранее фразу. 
Слова и фразы хранит в автоматически создающемся `dictionary.txt` файле внутри папки, где размещен сам скрипт.

## ⚡ Доступные версии скрипта

В репозитории представлено **две версии** программы. Вы можете выбрать наиболее подходящую под ваши задачи:

| Функция | Версия 1 (Защищенная) | Версия 2 (Легковесная) |
| :--- | :---: | :---: |
| **Детектор паролей** |  Есть (Авто) | ❌ Нет |
| **Защита конфиденциальности** | Средняя (не пишет пароли) | Ручная (пауза скрипта через `F12`) |
| **Скорость работы / Нагрузка** | Стандартная | ⚡ Максимальная |
| **Способ сохранения файла** | Перезапись файла | Оптимизированный (`FileOpen`) |

### В чем их отличие?

1. **Версия 1 (С защитой паролей):**
   * Содержит встроенный детектор `IsPasswordField()`.
   * **Как работает:** Обращается к Windows API и заголовкам окон браузеров. Если вы вводите пароль или находитесь на странице авторизации, перехват текста временно **отключается**, чтобы ваши секретные данные не попали в `dictionary.txt`.
   * **Кому подойдет:** Для ежедневного использования на личном/рабочем ПК.

2. **Версия 2 (Легковесная / Оптимизированная):**
   * Детектор паролей полностью вырезан.
   * **Как работает:** Скрипт не тратит ресурсы на проверку типа поля ввода при каждом нажатии клавиши, благодаря чему работает максимально быстро. Файл словаря обновляется через прямое файловое потоковое чтение (`FileOpen`).
   * **Кому подойдет:** Для работы с большими объемами текста, слабых ПК или если вы предпочитаете отключать скрипт вручную клавишей `F12` при вводе паролей.

## ✨ Основные возможности

- **🧠 Самообучаемый словарь:** Автоматически запоминает часто используемые слова, связки слов (биграммы) и целые предложения.
- **💡 Компактный оверлей:** Выводит до 6 подсказок (4 слова + 2 фразы) в правом нижнем углу экрана, не отвлекая от работы.
- **🔒 Защита приватности:** *(Только в Версии 1)* Автоматически распознает поля ввода паролей и формы авторизации в браузерах.
- **🔤 Умный регистр:** Автоматически подстраивает регистр вставляемого слова (ЗАГЛАВНЫЕ, С Заглавной, строчные) под то, как вы начали его писать.
- **🗑️ Быстрое удаление:** Возможность легко удалять ошибочно сохраненные слова или фразы прямо из интерфейса подсказок.
- **⚙️ Настройка авто-пробела:** Переключение автоматического добавления пробела после вставки через меню в трее.

## ⌨️ Горячие клавиши и управление

| Клавиша | Действие |
| :--- | :--- |
| `1` – `6` | Вставить соответствующий вариант из списка |
| `Enter` | Вставить 1-й вариант (когда окно подсказок активно) |
| `Shift` + `1` – `6` | **Удалить** выбранный вариант из базы данных |
| `Shift` + `Delete` | **Удалить** 1-й вариант из базы данных |
| `F12` | **Пауза / Возобновление** работы скрипта |

## 📥 Установка и запуск

### Требования
1. Установленный **[AutoHotkey v2.0](https://www.autohotkey.com/)** или новее.

### Запуск
1. Скачайте файлы репозитория.
2. Выберите нужную версию скрипта.
3. Убедитесь, что файл скрипта находится в папке, где разрешена запись (там будет создан файл базы данных `dictionary.txt`).
4. Запустите выбранный `.ahk` файл двойным кликом.

---

## 📁 Структура базы данных (`dictionary.txt`)

Скрипт автоматически создает и обновляет файл `dictionary.txt`. В нем хранятся:
- **Отдельные слова** с частотой использования (`слово: частота`)
- **Связки слов** для предсказания следующего слова (`слово1>слово2: частота`)
- **Целые фразы** для быстрого ввода предложений (`PHRASE>текст фразы: частота`)

## ⚙️ Настройки в Трее

Нажмите правой кнопкой мыши по иконке скрипта в **системном трее (возле часов)**:
- Включите/выключите **"Авто-пробел после автозавершения"**.
- Приостановите или завершите работу программы.
